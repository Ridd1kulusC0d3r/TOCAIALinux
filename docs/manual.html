TOCAIA OSINT LINUX

Uma distro de investigação em fontes abertas, leve, que roda em qualquer lugar e organiza as ferramentas pelas fases do método. Este manual foi escrito para quem nunca usou Linux.

01O que é

A TOCAIA é uma receita só que gera cinco formas de usar a mesma coleção de ferramentas. Você escolhe a que cabe no seu computador.

No celular: a edição Android "Matula" leva este mesmo desktop para o Android, com tela no celular, no PC ou na TV. Veja o manual da Matula.
Ética primeiro. Fonte aberta, sem invadir, sem enganar, sem assediar. As técnicas de ataque do war game existem só para treinar a defesa, em laboratório isolado.

Escolha a aba do seu caso. Em todas, o primeiro teste é o mesmo: ver a lista de ferramentas.

  4. Opcional, distro completa no WSL: com Docker Desktop instalado, rode sh container/exportar-wsl.sh e depois, no PowerShell, wsl --import TOCAIA $env:USERPROFILE\TOCAIA .\tocaia-wsl.tar. Para entrar: wsl -d TOCAIA -u analista.

  2. Baixe o ZIP do projeto e extraia.

  4. Opcional, container: com Docker Desktop, docker run -it ghcr.io/ridd1kulusc0d3r/tocaialinux.

03Como funciona

Tudo passa pelo trem. Ele lê o catálogo e decide como rodar cada ferramenta.

Por que é leve

As ferramentas de terceiros não vêm instaladas: só o nome delas está no catálogo. Elas descem da internet na primeira vez que você usa. As suas ferramentas são arquivos únicos de poucos KB.

04A jornada: o menu pelas fases

Kali e Parrot organizam por tipo de ferramenta. A TOCAIA organiza pelo método: navegando no menu, você aprende a ordem certa de uma investigação.

05Uso guiado

Esta é a tela real do comando trem (capturada nos testes). Os marcadores explicam cada parte.

1O comando. Sem nada depois, ele só lista. 2Resumo: quantas ferramentas já estão prontas para uso. 3A fase do método. As ferramentas aparecem na ordem da investigação. 4sob demanda: ferramenta de terceiros. Na primeira vez que rodar, ela se instala sozinha (precisa de internet). 5planejada: ferramenta sua que ainda vai ser empacotada. Rodar avisa e não quebra nada.

Primeira investigação, passo a passo

  1. trem opsec — confira o ambiente e marque o checklist antes de abrir o navegador.
  2. trem sherlock nome_de_usuario — procure o username nas redes (na 1ª vez instala).
  3. trem silencio posts.jsonl --fonte perfil --tempo data — veja quais perfis pararam de postar fora do ritmo deles.
  4. trem manifesto -o manifesto.json — registre as versões exatas das ferramentas que você usou e cite o ID no relatório.

06War game: ataque × defesa

O time vermelho (Tropeiro) executa técnicas reais do MITRE ATT&CK num laboratório. O time azul (Atalaia) defende com o Wazuh. O trem placar é o juiz.

Azul 101,5 × Vermelho 25. Cobertura 66,7%, MTTD médio 67,5 s. As lacunas T1053.005 e T1135 são o dever de casa do time azul. Repare no P6: o adversário apagou os logs, e foi justamente o silêncio que o entregou.

As regras completas e como subir o laboratório estão em wargames/README.md.

09Glossário

OSINTInteligência de fontes abertas: informação pública, obtida sem invadir nada.
OPSECCuidados para que a investigação não exponha o investigador.
TremCada ferramenta da distro, e também o nome do lançador.
.pyzPrograma Python empacotado num arquivo só.
venvAmbiente isolado onde uma ferramenta de terceiros instala o que precisa sem bagunçar o resto.
WazuhPlataforma aberta de SIEM/XDR: coleta eventos e gera alertas.
MITRE ATT&CKCatálogo público de técnicas de ataque, com códigos como T1059.
Atomic Red TeamTestes pequenos que reproduzem uma técnica de ataque em laboratório.
MTTDTempo médio até detectar.
Detecção pela ausênciaAlertar quando um sinal esperado some: o silêncio vira evidência.
Cadeia de custódiaRegistro que prova o que foi usado, quando, e que nada foi alterado.
ISO liveSistema que roda do pendrive sem instalar no computador.

Pontos de extensão

  • Novo cenário: JSON em wargames/cenarios/.
